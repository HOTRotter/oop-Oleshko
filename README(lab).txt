Описание

Проект представляет собой десктопное приложение для управления списком задач (Todo List), разработанное на платформе Windows Forms (C#) в рамках выполнения лабораторной работы. Приложение позволяет создавать задачи, отслеживать их выполнение, редактировать и удалять данные, а также сохранять текущее состояние списка между сессиями.

Функциональные возможности

1. Добавление задачи с указанием названия и приоритета.
2. Отметка задачи как выполненной.
3. Переименование существующих задач.
4. Удаление задач из списка.
5. Автоматическое сохранение данных в файл `tasks.json` (формат JSON) при закрытии приложения и загрузка при запуске. В случае отсутствия файла инициализируется пустой список.

Инструкция по запуску

1. Откройте файл решения `Lab1.sln` в среде Microsoft Visual Studio 2022.
2. Выполните сборку проекта (F5 или команда "Запуск").

Архитектура проекта

Код разделен на слои для соблюдения принципов инкапсуляции и разделения ответственности:

Модель (`TodoItem.cs`): Отвечает за хранение данных об одной задаче. Свойства `Title`, `IsCompleted` и `Priority` имеют модификатор доступа `private set`, что исключает их прямое изменение извне. Изменение состояния реализовано через методы `Complete()` и `Rename()`. Валидация на пустое название выполняется внутри модели, при нарушении выбрасывается `ArgumentException`.
Логика (`TodoList.cs`): Управляет коллекцией задач. Реализует методы добавления, удаления, а также сохранения и загрузки данных с использованием `System.Text.Json`. Класс не зависит от пользовательского интерфейса и не содержит элементов вывода.
Интерфейс (`MainForm.cs`): Отвечает за отображение данных и взаимодействие с пользователем. Обработка нажатий кнопок делегируется методам модели и логики. Возникающие исключения перехватываются с помощью конструкции `try/catch`, информация об ошибках выводится пользователю через `MessageBox`.




СООТВЕТСТВИЕ ТРЕБОВАНИЯМ (ЧЕК-ЛИСТ)

Модель, классы задачи и списка задач. Поля закрыты, изменение только через методы. В модели нет окна и вывода.
Выполнено: В классе TodoItem поля закрыты. Изменения происходят только через методы Rename() и Complete(). Классы TodoItem и TodoList не ссылаются на System.Windows.Forms.

Окно. Поле ввода, кнопка «Добавить», список задач с отметкой выполнения и дополнительным полем.
Выполнено: В MainForm реализованы текстовые поля txtTitle, txtPriority, кнопка btnAdd и список listBoxTasks.

Операции. Выполнить, переименовать, удалить. Список обновляется сразу.
Выполнено: Кнопки вызывают соответствующие методы. После каждой операции вызывается метод RefreshList(), который мгновенно обновляет визуальное отображение списка.

Ошибки. Пустое название, действие без выбранной задачи, неверное значение доп. поля: сообщение, программа работает дальше. Пустое название запрещено в модели.
Выполнено: Валидация пустого названия вынесена в модель TodoItem. В MainForm стоят блоки try/catch, которые перехватывают ошибки и выводят их через MessageBox, не прерывая работу приложения. Если задача не выбрана, выводится предупреждение.

Сохранение. Задачи сохраняются в JSON и загружаются при запуске. Нет файла: пустой список.
Выполнено: Используется System.Text.Json. При отсутствии файла tasks.json программа корректно инициализирует пустую коллекцию.
